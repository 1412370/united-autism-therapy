# Tasks

Delegated work is tracked here. Each task is one Markdown file using the template in `docs/agent-workflows.md` section 2.

- `active/`: tasks in progress or waiting for review. File name: `<YYYY-MM-DD>-<short-name>.md`.
- `completed/`: tasks whose acceptance criteria were verified. Move the file here; do not delete it.

The Main Agent creates and moves task files. Subagents only update the status of their own task.
